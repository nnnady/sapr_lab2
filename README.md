# Лабораторная работа №2 (САПР): устройство на шине APB

**Автор:** Токмакова Надежда Дмитриевна
**Группа:** М3О-409Б-23
**Вариант 11:** сложение по И с накоплением

## Описание

Устройство (слейв APB) хранит текущий результат и при каждой команде
выполняет `RESULT = RESULT & DATA`. После сброса RESULT = `FFFF_FFFF`
(для операции И это «нейтральное» значение: `x & FFFF_FFFF = x`).

## Регистры (базовый адрес `0x7000_0000`)

| Смещение | Регистр | Доступ | Назначение |
|---|---|---|---|
| 0x0 | DATA   | запись/чтение | добавляемое значение |
| 0x4 | CTRL   | запись/чтение | бит 0 START — выполнить `RESULT = RESULT & DATA`; бит 1 CLEAR — `RESULT = FFFF_FFFF`; бит 2 AUTO — накопление сразу при каждой записи в DATA |
| 0x8 | RESULT | только чтение | текущий результат |

START и CLEAR сами сбрасываются (при чтении CTRL они равны 0). Если записать
оба бита сразу, выполняется CLEAR. Запись в RESULT и обращение по другим
адресам — ошибка (`pslverr = 1`).
